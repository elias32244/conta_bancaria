# conta_bancaria

Projeto exemplo em TypeScript para a atividade "Projeto Conta Bancária".

Como usar:
1. `npm install`
2. `npm run build` (ou `npm run dev` para usar ts-node)
3. `npm start`

Arquivos principais:
- `src/util/Colors.ts` - Classe de cores ANSI para o terminal.
- `src/Menu.ts` - Classe principal com menu interativo.
- `src/index.ts` - Ponto de entrada que instancia e executa o menu.
